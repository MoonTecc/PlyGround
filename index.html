Quick Tips
• Drag items onto the canvas to spawn.
• Double-click an object on the canvas to inspect its properties.
• Edit density/friction and press Apply to update live.
• Objects marked 'Burnable' will ignite from nearby fire.

Encoder Console
Write a single command and press M while pointing at a target object to execute it.
Encoder Guide
• Use .command(args) syntax.
• Fire at a target with M to execute.
• Indentation-based blocks are supported:
if (.get(name)=="Box")
.burn()
else
.teleport(300,100)
• Try commands: .push(0.05,right), .size(1.5), .color(#ff00ff).
