Encoder Console
Write a single command and press M while pointing at a target object to execute it.
🖥️ ENCODER REFERENCE
⚡ SYNTAX
.command(arg1, arg2)
Double-click Encoder → write command → press M aimed at a target.
🔀 CONTROL FLOW
if(.get(name)=="Box")
  .burn()
else
  .teleport(300,100)
📦 MOVEMENT
.teleport(x, y) — snap position
.push(force, dir) — left/right/up/down
.setvelocity(vx, vy) — override velocity
.applyforce(fx, fy) — raw force vector
🔧 PROPERTIES
.size(scale) — resize body
.setdensity(n) — change mass
.setfriction(n) — surface grip
.rotate(deg) — rotate in degrees
.color(#hex) — repaint fill
.setlabel(name) — rename entity
🔥 ACTIONS
.burn() — ignite body
.transform(type) — morph to box/ball/etc
.delete() — remove from world
.makestatic() / .makedynamic()
🌀 GRAVITY WELL
.setgravity(force) — pull strength
.setgravity(force, radius) — force + range
📡 GET VALUES
.get(name) · .get(density) · .get(x)
.get(burning) · .get(mass) · .get(angle)
Double-click object → properties appear
